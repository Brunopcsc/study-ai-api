StudyBuddy AI - Backend API

StudyBuddy AI is a specialized web platform designed to assist students in preparing for public examinations (concursos) using Artificial Intelligence. This backend service provides an automated tutor that explains complex legal and administrative topics and generates dynamic multiple-choice quizzes to test the user's knowledge.
🚀 Technologies

This project leverages a modern Java stack to ensure scalability and ease of integration with AI models:

    Java 21 (Long-term support version)

    Spring Boot 3.4+

    Spring AI (Google Gemini Integration)

    Spring Data JPA (Persistence layer)

    Flyway (Database migrations)

    PostgreSQL (Relational database)

    Docker & Docker Compose (Containerization)

    Lombok (Boilerplate reduction)

🧠 Key Features

    AI Tutor Chat: Get detailed, context-aware explanations about any exam-related subject. The AI is prompted to act as a professional tutor, focusing on how specific topics are usually tested by major exam boards (CESPE, FGV, etc.).

    Dynamic Quiz Generation: Automated creation of 4-option multiple-choice questions based on the studied content, including full explanations for correct and incorrect answers.

    Progress Tracking: (In progress) Store user performance and study history for long-term analytics.
